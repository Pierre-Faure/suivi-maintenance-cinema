# Suivi maintenance & prestataires — Cinéma

Petite application web locale de suivi des maintenances, rendez-vous prestataires,
chantiers et vérifications réglementaires d'un cinéma. Objectif premier : la
transmission d'information à l'équipe en l'absence du responsable technique.

**État :** socle technique en préparation. Aucune fonctionnalité métier.

## Pile

Django 5.2 LTS · HTML rendu serveur + htmx · SQLite (WAL) · Docker.

## Environnement de développement

- Windows 11 + WSL2, distribution Ubuntu 26.04
- Docker Engine installé dans WSL (pas Docker Desktop)
- VS Code + extension WSL ; extensions recommandées dans `.vscode/extensions.json`
- Le projet vit dans le système de fichiers Linux (`~/projets/...`), jamais sous `/mnt/c`
